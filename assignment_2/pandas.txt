Pandas Data Cleaning Challenge

The Scenario:
You have been handed a raw sales dataset (replicated below) that is riddled with errors from manual entry. Your goal is to transform this "dirty" data into a clean, analysis-ready format.

Copy and run this code block to generate your starting point:

import pandas as pd
import numpy as np

data = {
    'Transaction_ID': [101, 102, 102, 103, 104, 105, 106, 107, 108],
    'Date': ['2023-01-01', '2023-01-02', '2023-01-02', '01/03/2023', '2023-01-04', np.nan, '2023-01-06', '2023-01-07', '2023-01-08'],
    'Customer': [' alice smith ', 'Bob Jones', 'Bob Jones', 'Charlie Brown', '  david lee', 'Eve White', 'Frank Miller', 'Grace Ho', 'Hank Hill'],
    'Product': ['Laptop', 'Mouse', 'Mouse', 'Tablet', 'Laptop', 'Tablet', 'Monitor', 'Mouse', 'Laptop'],
    'Price': [1200, 25, 25, 300, 1200, np.nan, 200, 25, 50000],
    'Quantity': [1, 2, 2, 1, 1, 2, 1, 3, 1]
}

df = pd.DataFrame(data)

Tasks:
1. Duplicate Detection: Identify and remove any duplicate rows.
2. String Normalization: Clean the Customer column by removing leading/trailing whitespace and converting all names to "Title Case."
3. Date Standardization: Convert the Date column into a proper datetime format. Ensure that inconsistent formats (like MM/DD/YYYY) are unified.
4. Missing Values:
	-Fill the missing value in the Price column with the median price of the dataset.
	-Remove any rows where the Date is still missing.
5. Outlier Handling: The laptop priced at 50000 is an entry error. Filter the dataframe to only include rows where the Price is less than 5000.
6. Feature Engineering: Create a new column called Total_Sales by multiplying Price and Quantity.
